# Tribute to Mrs. Abeer Ayoub | World Teachers' Day 💖

A luxurious, mobile-first cinematic tribute and interactive celebration web application dedicated to teacher **Mrs. Abeer Ayoub** by student **Ghalib Al-Jazi** on the occasion of World Teachers' Day.

## ✨ Highlights
- **Retro-TV Video Broadcast**: Elegant classic television frame with the student's video message in English (`gemini_generated_video_6520ed37.mp4`).
- **Heartfelt Typewriter Prologue**: Moving words of appreciation accompanied by typing sound effects via the Web Audio API.
- **Luxury Mobile Tribute Card**: High-contrast ruby red, velvet crimson, and champagne rose gold palette with custom glowing heart motifs.
- **Interactive Suite**:
  - 💖 Floating 3D-styled animated hearts and rose petals.
  - 📜 Live guestbook tribute drawer.
  - 📥 Instant high-resolution 9:16 portrait mobile wallpaper download (1080x1920).
- **Ultra Lightweight & Battery Friendly**: Event-driven canvas that sleeps at 0% idle CPU for buttery-smooth 60fps performance on mobile.
